# 校园食堂公共信息与数据展示中心

云南大学信息学院《软件开发综合实践》期末大作业作品。围绕"校园食堂"主题，整合首页、窗口查询、就餐统计、菜品浏览与三维导览五大模块，形成完整的校园生活服务响应式前端应用。

## 一、技术栈

| 技术 | 用途 | 说明 |
| --- | --- | --- |
| HTML5 + CSS3 | 页面结构与样式 | 语义化标签 + 自定义样式 |
| Bootstrap 5.3 | 响应式布局与组件 | 导航栏、栅格、卡片、表单 |
| 原生 JavaScript | 交互逻辑与数据处理 | fetch 加载 JSON、筛选、图表初始化 |
| ECharts 5.4 | 数据可视化 | 柱状图、饼图 |
| Three.js 0.160 | 三维展示 | 食堂三维场景（importmap + OrbitControls） |

> 不使用后端服务器，不使用 React / Vue 等未讲授框架。

## 三、在另一台电脑上从克隆到运行的完整步骤

### 方式一：直接用浏览器打开（最简单）

1. 把整个项目文件夹拷贝到目标电脑任意位置。
2. 用浏览器直接打开 `index.html` 即可浏览首页。
3. 注意：查询页、统计页、菜品页通过 `fetch` 读取 `data/canteen-data.json`，**直接双击打开（file:// 协议）时部分浏览器会拦截本地 fetch**，如出现"数据加载失败"，请改用方式二。

### 方式二：用本地静态服务器打开（推荐）

1. 安装 VS Code（如已安装可跳过）。
2. 在 VS Code 中安装扩展 **Live Server**（作者：Ritwick Dey）。
3. 用 VS Code 打开项目根目录。
4. 在文件树中右键 `index.html` → **Open with Live Server**，浏览器会自动打开 `http://127.0.0.1:5500/index.html`。
5. 此时所有页面（含 fetch 加载 JSON、三维页 importmap）均可正常运行。

### 方式三：用 Python 自带服务器

1. 确保已安装 Python 3。
2. 在项目根目录打开命令行，执行：
   ```
   python -m http.server 8080
   ```
3. 浏览器访问 `http://localhost:8080/index.html`。

### 运行环境要求

- 现代浏览器（Chrome / Edge / Firefox 较新版本）。
- 需联网：Bootstrap、ECharts、Three.js 通过 jsDelivr CDN 加载，首次运行需联网；离线运行可将对应 CDN 链接替换为本地文件。
- 三维页面需要浏览器支持 WebGL（绝大多数现代浏览器默认支持）。

## 四、功能模块说明

| 模块 | 页面 | 主要功能 |
| --- | --- | --- |
| 首页 | index.html | 食堂主图 Banner、统一导航栏、四个功能入口卡片 |
| 食堂查询 | canteen-list.html | 按楼层/窗口类型/开放状态三维筛选 + 关键字搜索，结果即时刷新 |
| 数据统计 | canteen-chart.html | ECharts 柱状图展示各窗口就餐人数 + 环状饼图展示占比 |
| 菜品浏览 | canteen-food.html | 按标签筛选菜品，展示名称、价格、所属窗口 |
| 三维导览 | three-d/canteen-scene.html | Three.js 食堂场景：地面、窗口柜台、取餐台、桌椅、横梁 |

## 五、交互功能清单

- 查询页：楼层 / 类型 / 状态下拉筛选（任一改变即刷新结果）。
- 查询页：关键字搜索框（输入即过滤，含非法字符校验）。
- 查询页：重置筛选按钮（清空全部条件）。
- 统计页：图表 tooltip 悬浮查看数值、图例点击显隐。
- 菜品页：标签按钮切换菜品列表。
- 三维页：鼠标左键旋转、滚轮缩放、右键平移。
- 全站：统一导航栏在五个页面间跳转，移动端可折叠。

## 六、错误提示与处理

项目对三类常见异常做了完整处理，对应报告第三章要求：

| 异常情况 | 处理方式 | 体现位置 |
| --- | --- | --- |
| 网络失败 / JSON 加载失败 | fetch `.catch` 捕获，页面显示红色"数据加载失败"提示，控制台打印错误 | 查询页、统计页、菜品页 |
| 数据为空 / 无匹配结果 | 显示"没有匹配的窗口/菜品，请调整筛选条件"提示 | 查询页 emptyTip、菜品页 emptyTip |
| 非法输入 | 关键字框校验 `< > " ' & \` 等字符，命中则显示红色"输入包含非法字符"并阻止查询；`maxlength=20` 限制长度；下拉框用枚举值避免非法选项 | 查询页关键字搜索框 |

## 七、数据来源

全部数据为模拟数据，统一存放于 `data/canteen-data.json`：

- `windows`：6 个食堂窗口（名称、楼层、类型、开放状态、编号）。
- `chart`：各窗口午餐就餐人数统计（窗口编号 + 数值数组 + 标题 + 单位 + 来源）。
- `foods`：8 道菜品（名称、价格、标签、所属窗口）。

各页面通过 `fetch('data/canteen-data.json')` 加载并解析展示，无任何后端接口。
